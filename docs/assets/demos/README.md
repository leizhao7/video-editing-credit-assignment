# Selected editing previews

These two animated previews compare an untrained base model with the corresponding released VideoEdit checkpoint on the same Fine Cut task and evaluation repetition:

- **Whiplash:** Qwen3.5-9B versus VideoEdit-Qwen3.5-9B, using decayed process rewards.
- **The Drama:** Qwen3.6-35B-A3B versus VideoEdit-Qwen3.6-35B-A3B, using fixed process rewards.

Each GIF shows the same four-second interval on both sides, at reduced resolution and frame rate for README display. They are drawn from the verified HD presentation reconstructions used on the project website. Original editing choices, timing, and defects are preserved; these are not new model outputs or additional evaluations. Scores belong to the original evaluated files.

The underlying films and video excerpts retain their respective rights and are outside the software's MIT license. These presentation examples are not a release of the training or validation dataset.
